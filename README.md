# Claude Certified Architect – Foundations (CCAR-F)

Community-maintained study materials for candidates preparing for the **Claude Certified Architect – Foundations (CCAR-F)** exam.

> **Status:** Independent study resource. This repository is not affiliated with, endorsed by, or an official publication of Anthropic. Practice questions are original study exercises, not actual exam questions.

## What is included

- `study-guide/` — supplied comprehensive study guide in DOCX, PDF and Markdown formats.
- `domains/` — study material organized by the five exam domains.
- `practice-questions/` — scenario-based practice questions and answer explanations.
- `diagrams/` — architecture diagrams for key concepts.

## Exam domains

| Domain | Weight |
|---|---:|
| Agentic Architecture & Orchestration | 27% |
| Tool Design & MCP Integration | 18% |
| Claude Code Configuration & Workflows | 20% |
| Prompt Engineering & Structured Output | 20% |
| Context Management & Reliability | 15% |

## Suggested study sequence

1. Read the exam blueprint and architecture mental model in the study guide.
2. Study Domain 1 through Domain 5.
3. Complete the scenario-based questions without viewing the answer key.
4. Perform the hands-on labs and validate version-sensitive implementation details against current official documentation.
5. Revisit incorrect answers and explain why the distractors are weaker.
